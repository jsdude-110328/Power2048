# Power2048의 공식 저장소에 오신 걸 환영합니다!

## 1. 이건 무슨 게임인가요?

2014년 이탈리아의 한 개발자가 만든 게임 2048을 약간의 게임적 변경을 거친 후 PowerShell 기반으로 제작해 콘솔에서 즐길 수 있도록 한 게임입니다. 2048의 공식 깃헙 링크는 https://github.com/gabrielecirulli/2048 입니다.

## 2. 그래서 왜 PowerShell인가요?

그냥요. Windows에서 설정 잘 건드시면 플레이하기 어렵지 않을 겁니다.

## 3. 어떻게 게임을 하나요?

크게 두가지 방법이 있는데 첫번째는 .exe 파일로 실행하는 겁니다. **웬만하면 보안을 위해 이걸로 실행하세요!**

두번째는 ps1 파일을 직접 실행하는 건데, 이건 혹여나 파일 실행 허가했다가 만약 인터넷에서 ps1 형식 악성코드 다운받아서 컴퓨터가 손상될 가능성이 있으니 비추천합니다.

## 4. 점수 조작해도 되나요?

마음대로 하세요, 당신이 results.txt 파일에 있는 점수를 1000점 올린다고 해서 실제 게임 점수가 1000점 올라간다는 보장은 없으니까요 :)
